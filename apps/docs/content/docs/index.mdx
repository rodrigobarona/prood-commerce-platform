## What you get

- **A store:** catalog, cart, checkout and customer accounts, on a prood.app address or your own domain.
- **A dashboard:** products, orders, customers, payment accounts, domains and team.
- **Hosted checkout:** cards, Multibanco and MB WAY through your own payment account, depending on your provider.
- **An API:** catalog, orders, customers, inventory and store settings all run on `/v1`, the same calls the dashboard makes, with an OpenAPI 3.1 spec and an MCP server.

Payment accounts, domains, team and keys stay in the dashboard.

## What stays yours

- **Your domain.** Every plan includes one custom domain or more, with HTTPS set up for you.
- **Your payment accounts.** Each store's credentials are stored separately and encrypted at rest with AES-256-GCM. Payouts go straight from your provider to you.
- **Your API keys.** Organization keys for your own code.
- **The final say.** With Agent Auth, an AI agent starts with nothing until you approve it for your store. After that it keeps the public catalog, and anything else needs your approval. You see every capability the agent asks for and approve or deny the request as a whole. Approved access ends after an hour idle, or 24 hours at most. Then the agent asks again. An API key isn't Agent Auth: anything holding an admin key can do what the key allows, without asking. Agent Auth starts on Grow. Paid plans are coming.
