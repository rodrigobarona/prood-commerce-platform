`@prood/payment-ifthenpay` implements the `PaymentProvider` interface for [Ifthenpay](https://www.ifthenpay.com/) — a Portuguese payment gateway supporting Multibanco, MB WAY, and credit card payments.

## Installation

```bash
pnpm add @prood/payment-ifthenpay
```

## Usage

```ts
import { IfthenpayPaymentProvider } from '@prood/payment-ifthenpay'

const provider = new IfthenpayPaymentProvider({
  antiPhishingKey: process.env.IFTHENPAY_ANTIPHISHING_KEY!,
  mbKey: process.env.IFTHENPAY_MB_KEY!,
  mbwayKey: process.env.IFTHENPAY_MBWAY_KEY!,
  ccKey: process.env.IFTHENPAY_CC_KEY!,
})
```

## Configuration

| Field | Env var | Description |
| --- | --- | --- |
| `antiPhishingKey` | `IFTHENPAY_ANTIPHISHING_KEY` | Anti-phishing verification key |
| `mbKey` | `IFTHENPAY_MB_KEY` | Multibanco gateway key |
| `mbwayKey` | `IFTHENPAY_MBWAY_KEY` | MB WAY gateway key |
| `ccKey` | `IFTHENPAY_CC_KEY` | Credit card gateway key |

`mbKey` is required, since Multibanco is the default method. The other keys are optional, and each one unlocks its method at checkout.

Ifthenpay has no read-only call to test keys with, so they aren't tested on save. It has no refund API either: refunds happen in the Ifthenpay backoffice, then the merchant records them in the dashboard.

## Selecting a method

Pass `method` on `createSession()` (defaults to `multibanco`):

| `method` | Key used | Result |
| --- | --- | --- |
| `multibanco` | `mbKey` | Entity + reference in `providerData` |
| `mbway` | `mbwayKey` | MB WAY push; `providerData.requestId` |
| `card` | `ccKey` | Redirect to Ifthenpay hosted card page |

```ts
const session = await provider.createSession({
  amount: 49.9,
  currency: 'EUR',
  orderId: 'ord_123',
  method: 'mbway',
  customer: { phone: '912345678' },
})
```

Reference-based methods (Multibanco) confirm asynchronously — the webhook callback is the source of truth, not a synchronous capture.

## Factory usage

```ts
import { getPaymentProvider } from '@prood/commerce'

const provider = await getPaymentProvider('ifthenpay', orgId)
```

## Payment methods

| Method | Key | Flow |
| --- | --- | --- |
| **Multibanco** | `mbKey` | Entity + reference; async ATM/homebanking payment |
| **MB WAY** | `mbwayKey` | Phone push notification |
| **Credit card** | `ccKey` | Redirect to Ifthenpay hosted page |

## Anti-phishing verification

Ifthenpay uses an anti-phishing key to verify webhook authenticity. The provider validates incoming webhooks against this key before processing.

## Webhook setup

The integration form shows the callback URL for your store. Send it to Ifthenpay with your anti-phishing key:

```
https://checkout.example.com/api/webhooks/ifthenpay/{orgId}?key=[ANTI_PHISHING_KEY]&orderId=[ORDER_ID]&amount=[AMOUNT]&requestId=[REQUEST_ID]
```

Order ids are encoded to fit Ifthenpay's 25-character limit and decoded when the callback arrives.
