Agencies use Prood to launch client stores without rebuilding checkout and admin for each job.

Running several client stores? Email us at hello@prood.com.

## How client stores work

- **Each store is its own organization.** It has its own catalog, orders, customer records, API keys, payment accounts and team.
- **One login.** Use **Add store** in the store switcher, at the top of the dashboard sidebar, and move between stores from the same menu.
- **A prood.app address straight away.** You choose your store's prood.app address when you sign up. If it's taken, we add a few characters to the end. Use the address for client review.
- **Client-owned payments.** Connect the client's own Stripe, Easypay or Ifthenpay account. Each store's credentials are stored separately and encrypted at rest with AES-256-GCM.
- **Custom domains.** Every store can use the client's own domain. Free includes one.
- **Their own logins.** Team invites start on Grow, and Free has one seat, the owner. Paid plans can't be bought yet.

## From kickoff to live store

1. **Add the store.** Open the store switcher, choose **Add store**, give it the client's name and choose its **Store address**.
2. **Build the catalog.** Add products in the dashboard. Products have prices, descriptions and an in-stock switch. Uploading product photos is coming later.
3. **Connect payments.** Enter the client's own credentials under **Payments**.
4. **Review.** Share the store's prood.app address with the client.
5. **Go live.** Add the client's domain under [Domains](/docs/apps/dashboard/domains). They add the DNS record at their registrar, and HTTPS is set up for you.
6. **Stay on.** Keep running the store for them. A store's data can be downloaded from its settings, but a store can't be passed to a new owner yet, so it stays with the account that created it. Changing a store by API starts on Grow. Paid plans are coming.

## Automation

Free keys reach the 21 storefront tools and the public storefront API: catalog, carts and placing orders. From Grow, each store can use:

- The full [REST API](/docs/api) and [MCP server](/docs/apps/api/mcp) for catalog and order work
- [Agent Auth](/docs/apps/api/agent-auth) for AI agents you approve

Agent Auth is coming with Grow. Every key and agent works on one store at a time.
