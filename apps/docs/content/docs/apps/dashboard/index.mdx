The dashboard at [dashboard.prood.com](https://dashboard.prood.com) is where you run your store. Sign in with your email and password. If you run more than one store, the store switcher at the top of the sidebar moves between them, and **Add store** creates another.

## What's in the sidebar

### Store

| Page | What you do there |
| --- | --- |
| Overview | See how the store is doing and what's left to set up |
| Orders | Fulfill, cancel and refund |
| Products | Add and edit products |
| Customers | See every customer with their order history |

### Connections

| Page | What you do there |
| --- | --- |
| Domains | See your Prood address and add your own domain |
| Integrations | Connect a payment account |
| API keys | Create and revoke keys. Store owners and admins only |

### Organization

| Page | What you do there |
| --- | --- |
| Team | Invite and remove people. Invites start on Grow |
| Store settings | Store details, contact details and region |
| Billing | See your current plan. Paid plans are coming |

Developers can read how the dashboard is built in [Dashboard internals](/docs/architecture/dashboard).
