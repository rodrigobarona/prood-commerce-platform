Products have prices, descriptions and an in-stock switch.

Uploading product photos, variants, categories and stock counts are coming later to the dashboard.

## Product list

**Products** lists everything in your store, with each product's name, status, type, date added and price. Search it, filter it by status, or sort it by name, date or price.

## Add a product

Choose **Add product**. It stays a draft until you set it to active.

### Details

| Field | What it does |
| --- | --- |
| Name | Required. What customers see |
| Description | Shown on the product's page |
| URL slug | The product's address on your store. Leave it empty to make one from the name |

### Pricing

| Field | What it does |
| --- | --- |
| Price | What customers pay. Active products need one |
| Compare-at price | The old price, shown crossed out next to the new one |

### Status

| Status | What it means |
| --- | --- |
| Draft | Hidden from customers while you work on it |
| Active | On sale. Customers only see active products |
| Archived | Hidden and out of the way, without deleting it |

### Inventory

| Field | What it does |
| --- | --- |
| SKU | Your own product code |
| In stock | Switch it off when you've run out |

### Type and shipping

| Field | What it does |
| --- | --- |
| Type | Physical, Digital, Service or Event |
| Requires shipping | On for anything you post. Choosing Digital turns it off |

## Edit or delete a product

Open a product from the list. **Save changes** appears as soon as you change something. To delete it, scroll to the bottom of the page.

## Limits

Free includes 50 products. At 50 you can't add more. See [Plans and limits](/docs/billing/plans).
