**Payments**, under **Connections**, is where you connect your own payment account. Each store's credentials are stored separately and encrypted at rest with AES-256-GCM.

## Providers

| Provider | What it adds |
| --- | --- |
| **Stripe** | Cards, plus Apple Pay and Google Pay where you've enabled them |
| **Easypay** | Multibanco, MB WAY and cards |
| **Ifthenpay** | Multibanco, plus MB WAY and cards if you enter their keys |

Each provider shows whether it's connected. Each store's checkout runs on one provider, and Stripe comes first if it's connected.

## Connect a provider

Open a provider and enter its credentials:

| Provider | Fields |
| --- | --- |
| **Stripe** | Publishable key, secret key, webhook signing secret |
| **Easypay** | Account ID, API key, and an optional Easypay address |
| **Ifthenpay** | Anti-phishing key, Multibanco key, and optional MB WAY and credit card keys |

Saving a new provider turns it on. Stripe and Easypay keys are tested when you save. Ifthenpay can't test keys, so place a small order to check them.

The same page shows your store's webhook URL. Orders are only marked as paid when your provider calls it, so add it in your provider's account. See [Webhook setup](/docs/guides/webhook-setup).

## Turn a provider off

Switch off **Turned on** and save. Your store stops taking new payments through it. It still reports on payments it took before.
